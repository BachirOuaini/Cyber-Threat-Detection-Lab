# Cyber Threat Detection Lab

## Overview
This project is a hands-on Cyber Threat Detection Lab built to simulate real-world SOC (Security Operations Center) environments and attack detection workflows. The lab integrates Wazuh, Caldera, and MISP to monitor endpoints, simulate adversary techniques, and enrich security events with threat intelligence.

The objective of this project was to gain practical experience in SIEM deployment, endpoint monitoring, threat detection, red-team simulations, and threat intelligence integration.

## Project Components

### 1. Wazuh Installation
- Deployed and configured Wazuh for centralized log collection and monitoring.
- Configured dashboards and event analysis capabilities.

### 2. Windows 10 Agent Installation
- Installed and connected Windows 10 agents to the Wazuh manager.
- Verified endpoint communication and event ingestion.

### 3. Caldera Setup and Agent Configuration
- Installed MITRE Caldera for adversary emulation.
- Added Windows agents for attack simulation testing.

### 4. Red-Team Simulation
- Executed simulated attack techniques using Caldera.
- Monitored generated events and alerts through Wazuh.

### 5. MISP Integration
- Installed and configured MISP for threat intelligence sharing.
- Integrated MISP with Wazuh to enrich alerts with threat intelligence indicators.

### 6. Event Monitoring & Detection
- Demonstrated event collection, detection workflows, and alert visibility.
- Validated threat intelligence ingestion from MISP into Wazuh.
